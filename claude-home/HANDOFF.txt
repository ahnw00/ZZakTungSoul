3. 폴더 구성
---------------------------------------------------------------------
claude-home\
  HANDOFF.txt                  <- 이 문서
  deck\ZZakTungSoul_v3.pptx    <- 현재 최신 덱(32장). 시작은 항상 이 파일 복사본으로.
  tools\insert_gif.ps1         <- GIF 삽입 스크립트(테스트 완료)
  build\                       <- 덱을 코드로 다시 만드는 소스(큰 구조 변경이 필요할 때만 사용)
    lib2.ps1 lib3.ps1          헬퍼(색/카드/칩/표/노트 등)
    r1.ps1                     모든 슬라이드 내용 + 슬라이드 노트
    main3.ps1                  빌드 실행 -> build\out3\deck.pptx 와 PNG 렌더(out3\png)
    template.pptx              원본 템플릿(푸터 로고 그룹 복제용, 삭제하지 말 것)
    img\                       슬라이드에 쓰는 이미지

- 작은 수정(텍스트/도형 위치, GIF 삽입 등)은 deck의 pptx를 직접 COM으로 편집하는 게 가장 빠르다.
- 슬라이드 여러 장을 구조적으로 바꾸려면 build\r1.ps1 을 고치고 main3.ps1 을 다시 실행한다.
    powershell -NoProfile -ExecutionPolicy Bypass -File build\main3.ps1
  (주의: 재빌드하면 insert_gif 로 넣은 GIF는 사라진다. 재빌드 후에는 insert_gif.ps1 을 다시 실행할 것.)
- 이 PC에서도 build\main3.ps1 이 그대로 동작한다(경로는 $PSScriptRoot 기준, 이식성 테스트 완료).
  PowerPoint 가 설치되어 있고, 맑은 고딕 폰트가 있어야 한다.

   단, 팀 구성 슬라이드와 4~7번 "담당 작업" 슬라이드는 예외(담당 소개).
4) 코드와 관련된 주장은 실제 소스(C:\Workspace\Unreal\ZZakTungSoul\Source)와 대조해서 쓴다.
   예) 인벤토리 델리게이트는 OnItemObtained(획득) 하나뿐, Warrior가 저장용으로 바인드, UI는 컨트롤러가

5) 근거가 없는 내용은 만들지 않고 "(작성 예정)" / "확인 필요"로 표시한다.

7. 알려진 함정 (PowerShell 5.1 + PowerPoint COM)
---------------------------------------------------------------------
- 한글이 들어간 .ps1 은 반드시 UTF-8 BOM 으로 저장(없으면 문자열이 깨짐). 파일을 편집한 뒤 BOM 을 다시 붙일 것:
    $t=[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8); [IO.File]::WriteAllText($p,$t,(New-Object Text.UTF8Encoding($true)))
- Line.Weight / Rotation 에는 [single] 캐스팅이 필요하다.
- 배열 안에서 문자열 연결은 괄호로 감쌀 것: @( ('a' + "`r" + 'b'), 'c' ).
- 함수 호출 결과를 쓰지 않을 때는 $null = Func ... 로 받아서 출력이 새지 않게 한다.
- webp 이미지는 PresentationCore(BitmapDecoder)로 PNG 변환한 뒤 System.Drawing 으로 잘라서 넣었다.
- 텍스트 넘침 자동 검사: 빌드 마지막에 "Warnings: 0" 이면 넘침 없음. 렌더 PNG(out3\png)로 눈으로도 확인.
